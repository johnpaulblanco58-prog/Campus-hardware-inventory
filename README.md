# Engineering Laboratory System

A Laboratory Equipment Inventory and Reservation Management System.

## Features

- User Registration
- Account Verification
- Secure Login
- Three-Attempt Account Lockout
- Password Reset Requests
- Administrator Password Reset Approval
- Hardware Inventory
- Equipment Search
- Category Filtering
- Equipment Reservation
- Reservation Approval
- Equipment Borrowing
- Equipment Return
- Add Equipment
- Update Equipment
- Delete Equipment
- CSV Inventory Export

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Pydantic
- bcrypt
